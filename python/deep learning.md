# MLP

## 基础

_常见的激活函数有哪些?_
```
🌟sigmoid： y(x) = 1/1+e^(-x)
🌟ReLU函数：y(x) = max(0, x)
🌟Tanh函数
🌟softmax函数(分类问题输出层激活函数)

🌙 激活函数可以是任意函数， 反向传播要求必须能求导
🌙 softmax还可以用于归一化
```

_为什么隐藏层的激活函数必须是非线性函数？_
```
三层神经网络等效于函数f(X) = h(h(W.h(WX+B)+B)+B), 其中h是每一层的激活函数， 假设h为线性函数， 由于WX+B也是线性函数：
多个线性函数的复合f(X)也是线性函数无法解决非线性问题
```

_MLP前向传播的过程?_
```
中输入X开始重复计算隐藏层神经元值A = 隐藏层激活函数(W.X + B)，并记录中间变量便于梯度后向传播的计算, 最终计算到Loss
```

_为什么对于复杂任务增加神经网络深度/架构比增加宽度效果更好？_
```
🌟 深度网络能以指数级更少的参数实现相同的性能, 参数效率更高
🌟 复杂问题往往可以拆分为多个简单问题（甚至模块化思考，复用模块）， 增加宽度相当于增加每一步的思考量减少思考步骤
```

## SGD

_怎样收敛神经网络中W和B等参数？_
```
通过已知的X和Y（训练集）， 让神经网络函数f去拟合X和Y使得f(X)逼近Y, 定义损失函数Loss(W, B) = Y-f(X), 找到使得Loss最小的点(W,B)即可， 从梯度的视角来说：
1️⃣ 从任意初始点（W0, B0）开始， 求当前点的梯度，朝着梯度下降的方向前进一段距离理论能最快接近局部最低点
2️⃣ 假设前进一段距离后点为（W1, B1）， 重复上述过程， 直到找到一个局部最低点

🌙 神经网络找到的局部最低点不一定是全局最低点
🌙 每次朝梯度下降方向前进的距离被称为“learn rate”
```

_常见的Loss函数有哪些?_
```
🌟 MES均方误差(回归问题)
🌟 Cross-Entropy函数
```

_什么是mini-batch和epoch?_
```
在训练集样本(X, Y)数量很多的时候, 没办法一次输入全部的X进行计算, 将X随机拆分为多个mini-batch, 在每个mini-batch上进行梯度下降

🌙 处理一批mini-batch的过程成为epoch
```

## Backpropagation

_有哪些方式可以计算 Loss 函数的梯度?_

```
🌟微分法: 梯度 = [Loss(W + h) - Loss(W-h)] / 2h, h=极小值
🌟BP算法

🌙 微分法速度很慢, 因为即使最简单的神经网络中参数也有百万个, 每次计算一次梯度要进行百万次矩阵运算
🌙 正是有了BP算法， 神经网络才得以发展， BP算法灵感也来源与人类的神经元反馈过程
```

_反向传播算法的原理是什么?_
```
链式法则

🌙 神经网络本质上是多个函数的符合, 反向传播相当于对函数Loss(Y(h(X)))从外到内依次求导, 并将导数从后往前传播
```

_常见的神经网络分为哪些层?_

```
🌟 Linear层： WX+B计算
🌟 sigmoid层/reLU层： 激活函数计算
🌟 softmax层：输出层
🌟 MSE层: Loss层

🌙 上面提到的是最简单的神经网络， 实际上有很多其他层
```

## 优化技巧

_学习率过大和过小会造成什么结果? 学习率如何设定?_

```
🌟 过大: Loss函数值在最小值附近震荡, 始终不能收敛到最小值
🌟 过小: 收敛需要的迭代次数增多, 并且更容易收敛到局部最小值

🌙 Adam优化学习率会动态衰减，还模拟了梯度下降时的物理惯性，避免过快掉入局部最低点陷阱
```

_初始权重参数如何设置?_
```
Kaiming初始化, 控制权重初始分布使得前向传播和后向传播的方差合理, 但训练过程中的分布偏移无法解决
```

_什么是梯度消失和梯度爆炸?_
```
🌟 梯度消失: 激活函数为S型曲线时, 连续多个神经网络层梯度小于1, 反向传播后梯度无穷小无法学习
🌟 梯度爆炸: 激活函数为S型曲线时, 连续多个神经网络层梯度很大, 反向传播后梯度无穷大溢出

🌙 深层神经网络梯度消失和爆炸问题更明显
```

_Batch Normalization层的作用?_
```
BN层在激活函数层前, 在神经网络初始阶段可以让输入信号符合标准高斯分布, 可以使训练更稳定

🌙 BN层out=gamma.X^ + bata, 初始化时out符合(0,1)分布, 但允许后续训练过程中分布偏移
```

_还有哪些训练技巧或方法?_
```
🌟 Dropout方法: 添加DropOut Layer随机删除神经网络中的神经元
🌟 Data Augmentation: 通过对训练集的样本图像进行平移, 旋转等技巧变换出新的训练集, 从而增大训练集大小
```

_多模态是怎么实现的?_
```
将图像/视频/音频离散化分块转换为token
   - 图像：按固定大小分块（如16×16像素→1个Token）  
   - 视频：时空分块（时间轴切帧+空间分块）  
   - 音频：梅尔频谱图分块 

🌙 不同模态直接会插入分割token: [TEXT] 描述这张图片 [IMAGE] <img_token_1>...<img_token_N> [AUDIO] <aud_token_1>...
```

_self-attention中Q K V三个矩阵的作用?_
```
示例: "The cat sat because it was tired", 假设嵌入维度C=6, 注意力维度H=2
🌟 嵌入后的向量, 每维代表一个特征
x["cat"] = [ 是名词,  有生命,  是实体,  可被指代, 不是动作,  主语候选 ]
x["it"]  = [ 非名词,  无生命,  非实体,  在指代名词, 不是动作,  主语候选 ]

🌟 q = Q.x 查询空间的向量, 每维表示"在这个通道上寻找什么"
q["cat"] = [ 寻找非名词实体,    寻找修饰它的词 ]
q["it"]  = [ 寻找名词实体,    寻找可被指代对象 ]

🌟 k = K.x 被检索空间的向量, 每维表示"在这个通道上提供什么"
k["cat"] = [ 是名词实体,       可被指代 ]
k["it"]  = [ 非名词实体,       在指代名词 ]

🌟 wei = q.k 注意力强度向量, 逐通道点积求和, 衡量"需求"与"供给"的匹配度
wei["it", "cat"] = q["it"] · k["cat"], 在经过softmax后就是it对cat的注意力强度

🌟 v = V.x 交流空间向量, 被选中后传递的信息
v["cat"] = [ 是有生命实体,  是名词 ]
v["it"]  = [ 无实体信息,  是代词 ]

🌙 q=我想匹配什么  k=我能被怎样匹配 v=被选中后交流什么
```
